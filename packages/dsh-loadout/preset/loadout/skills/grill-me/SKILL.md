# Grill Me

1. Identify gaps in the outcome, users, scope, constraints, success criteria, and meaningful edge cases. Research facts in the repository, config, data, or history.
2. Ask one material user-owned question per message. Give a recommendation and the reason it fits the evidence. Wait for the answer before the next question and continue independent work where possible.
3. Resolve reversible details and choices the user delegates. Stop asking once the request is actionable.
4. Summarize the outcome, scope, constraints, and verification in 2–5 sentences. For an implementation request, use the brainstorming skill if material design choices remain. Otherwise, implement.
